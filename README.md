# The Idle Register

A picture-driven choose-your-own-adventure about seeds, quotas and a corporation that owns every harvest. Around 5 minutes a run, 16 beats, 8 endings.

**Play:** [https://akshatjerath.github.io/agc-game/](https://akshatjerath.github.io/AGC-Game/) (or open `index.html` in Chrome).

## Files
| File | What it holds |
|---|---|
| `index.html` | Screens: menu, intake, corner ledger, end screen, endings gallery |
| `style.css` | Look and motion |
| `story.js` | Every caption, choice, timer and ending, as editable data |
| `game.js` | The engine: video crossfades, timers, flags, saved endings |
| `videos/` `images/` `fonts/` | Scene clips, posters, bundled typefaces |

Keys: **1–3** pick a choice, **F** toggles fullscreen.

Made by Akshat Jerath for the Critical Design course, MDes Design Futures, ATLAS SkillTech University.
